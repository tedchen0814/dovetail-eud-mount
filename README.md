# 胸掛 EUD 鳩尾槽提案

軍規胸掛（Chest Mount / MOLLE-PALS EUD Mount）與 5 吋手持平板（EUD）鳩尾槽機構的 10 個結構提案與 3 種組合，含裝上／取出互動動畫（正視圖＋A–A 剖面）。

- 網頁：`鳩尾槽提案動畫.html`
- 提案筆記：`胸掛EUD鳩尾槽_收斂10提案.md`（主文件）、`胸掛EUD鳩尾槽_10種提案.md`（中央單軌）、`胸掛EUD鳩尾槽_雙軌10種提案.md`（上下雙軌）、`鳩尾槽設計_查證.md`

內容為概念構想，尚未驗證；厚度為估算值，圖為示意、非實際比例。

## 部署

```
node build.js
cd dist && npx vercel deploy --prod --yes --scope ted-hq --project dovetail-eud-mount
```
